PROJECT / SPRING 2023

Furious Rogue

Project Snapshot

Role: Developer

Tools: Unity, C#, GitHub

Team: Developed with 2 other people

Overview

This project was developed for a intermediate game class. we had roughly 6 weeks to make a game of our choosing and we choose to do a dungeon crawler-type action game.

you control a rogue who is furious and must fight through evil minotaurs. you have a sword for attacking, a dash to doge enemy attacks, and light puzzle elements to complete each level. there are 3 levels and at the end of level 3 you fight a more beefed up minotaur boss to win the game

the development for this game was mostly me leading a group of 2 other people about the tasks we need to get done, and how our design and development should progress. I was assigning who does what, and pushing for my team wot stick with the project and finish it to the end. I had to handle merge conflicts through GitHub and worked on getting everyones code inside the same project working together.

My Role

While developing this game for class, I spent about 8 hours a week on the project implementing my mechanics inside of unity.

  • Created a 2D top-down action adventure game in Unity where you must defeat minotaur’s and complete puzzles to reach the final boss.
  • Was the programmer and helped my team get together and make our code work.
  • Worked on the physical movement for the characters, as well as implementing health, screen transitions, push able objects, and combat.
  • Combined everyone else’s work/code into the game so that nothing would break, and everything would continue to work as intended using source control/GitHub.
