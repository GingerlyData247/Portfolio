PROJECT / SUMMER 2023

2D Game Engine

Project Snapshot

Role: Developer

Tools: Java, VSCode, minor use of ChatGPT

Team: Sole Developer

Overview

This was a project I worked on for a 2D game engine class. the purpose of this project was to make a small 2D game engine, made to specifically play a game I make.

This project was done in Java and I had to worry about how to handle everything such as sprites rendering, the hit boxes of those sprites, movement of the character and scene changes

My Role

this project was developed by myself applying java canvas rendering to develop the project

  • Developed a lightweight 2D game engine prototype in Java with sprite rendering, input handling, collision detection, and basic physics.
  • Built gameplay logic for movement, jumping, gravity, collision response, restart conditions, and victory detection within a custom Swing application.
  • Applied object-oriented design by separating responsibilities across sprite, input, handler, and rendering classes
